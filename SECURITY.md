# Security Policy

## Supported Versions

Fantoche is pre-1.0. Only the newest release receives security fixes.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Report privately via GitHub's vulnerability reporting for this repository:
[Report a vulnerability](https://github.com/fantoche-dev/fantoche/security/advisories/new).

After receiving a report, we will try to confirm the problem and respond within
48 hours with our plans for the reported issue. If applicable, a fix is prepared
and released as fast as possible.

## Upstream projects

Fantoche is a fork of Revideo, itself a fork of Motion Canvas. If a
vulnerability also affects the upstream projects, please report it to them as
well: Revideo at [hello@haven.run](mailto:hello@haven.run), Motion Canvas at
[aarthificial+motion-canvas@gmail.com](mailto:aarthificial+motion-canvas@gmail.com).
